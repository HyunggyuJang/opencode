Launch a subagent for complex or multi-step tasks.

Available agent types and the tools they have access to:
{agents}

Required: subagent_type.

Usage notes:
- Use this tool for slash commands when instructed.
- Provide a detailed prompt and the expected output.
- Each agent is stateless unless you pass session_id; reuse it to resume a prior subagent.
- Results return as a single message; summarize it for the user.
- Run independent subagents in parallel.
- Avoid Task for simple file reads or small searches; use Read/Glob/Grep instead.
