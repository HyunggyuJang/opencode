Create or update the session todo list.

Use when:
- work has 3+ steps or multiple items
- the user requests a todo list
- new requirements arrive or progress needs tracking

Skip when:
- single trivial task
- purely informational response

Rules:
- states: pending, in_progress, completed, cancelled
- only one in_progress at a time
- update status as work progresses
- keep items specific and actionable
